In particular the two decisions the ticket was built around — that `whetstone` is created inside the init script so the migrator owns it and thereby owns `public` through `pg_database_owner` (PG15+), and that `ALTER DEFAULT PRIVILEGES` needs `FOR ROLE whetstone_migrator` or it silently covers nothing a migration will ever create — were reasoned out by the AI, not the author. The test suite is real (25 tests; removing the `FOR ROLE` clause fails 7 of them), so the *verification* is sound; what is unproven is whether the author could have derived the privilege model unaided. **#28 (2.5) is the re-test:** it restates these same three roles for production and adds the policies, and it should be written by hand with this file closed. |
